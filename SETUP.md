## 🛠️ Guia Definitivo: Como Rodar Localmente

Para rodar este dApp na sua máquina, você precisará configurar o Frontend, o Backend (Supabase) e o Ambiente Web3.

### Passo 1: Ferramentas Necessárias
* [Node.js](https://nodejs.org/) (Versão 18 ou superior)
* Extensão da [MetaMask](https://metamask.io/) no navegador.
* Instância do Supabase configurada com as tabelas `vagas` e `propostas`.

### Passo 2: Configurando o Banco de Dados (Supabase)
1. Crie uma conta em [Supabase](https://supabase.com/) e inicie um novo projeto.
2. No painel lateral, vá em **SQL Editor** e clique em "New Query".
3. Cole e execute o código SQL abaixo para criar as tabelas:

```sql
-- Criar tabela de Vagas
CREATE TABLE vagas (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  titulo TEXT NOT NULL,
  descricao TEXT NOT NULL,
  valor NUMERIC NOT NULL,
  token_address TEXT NOT NULL,
  contratante_address TEXT NOT NULL,
  escrow_address TEXT,
  status TEXT DEFAULT 'aberta',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Criar tabela de Propostas
CREATE TABLE propostas (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  vagas_id BIGINT REFERENCES vagas(id) ON DELETE CASCADE,
  freelancer_address TEXT NOT NULL,
  valor_proposto NUMERIC NOT NULL,
  prazo_dias INTEGER NOT NULL,
  comentario TEXT,
  status TEXT DEFAULT 'pendente',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```
Vá em Project Settings -> API e copie a sua Project URL e a anon public key.

### Passo 3: Credenciais Web3 (WalletConnect)
Acesse o WalletConnect Cloud.

Crie um projeto novo e copie o seu Project ID.

### Passo 4: Instalação e Variáveis de Ambiente
Clone o repositório e acesse a pasta:

```bash
git clone https://github.com/Dafloresz/escrow-freelancer-web3
cd frontend/
```
Instale as dependências:

```bash
npm install
```

Crie um arquivo .env.local na pasta frontend e adicione suas chaves:

```Snippet de código
# Chave do WalletConnect (Passo 3)
NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID="cole_seu_project_id_aqui"

# Chaves do Supabase (Passo 2)
NEXT_PUBLIC_SUPABASE_URL="cole_sua_project_url_aqui"
NEXT_PUBLIC_SUPABASE_ANON_KEY="cole_sua_anon_key_aqui"
```

Inicie o servidor:

```Bash
npm run dev
```

O projeto estará rodando em http://localhost:3000.

Passo 5: Preparando a MetaMask (Fundos de Teste)
Para simular as contratações, sua carteira precisa estar conectada à rede Sepolia Testnet.

Na MetaMask, habilite "Mostrar redes de teste" e selecione Sepolia.

Pegar ETH de Teste: Acesse o Alchemy Sepolia Faucet e solicite fundos.

Pegar USDC de Teste: Importe o token USDC da testnet (0x1c7D4B196Cb0C7B01d743Fbc6116a902379C7238) na sua carteira. Você precisará cunhar (mint) tokens de teste interagindo com o contrato via Etherscan ou utilizando faucets de protocolos da Sepolia.
